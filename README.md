# BurnScope

用于 CPU 和 GPU 双烤、内存和显存测试。

## 安装与运行

需要 Python 3.12 或更新版本，在本目录运行

```sh
python -m pip install -r requirements.txt
python main.py
```

## 界面

- CPU 测试默认使用全部可用逻辑核，多进程执行整数和浮点计算并校验结果。可以调节目标负载。
- GPU / 显存测试只枚举真实 OpenCL GPU
- 内存使用保守自动预算，默认不超过 1 GiB、可用内存的 50%，并保留至少 2 GiB。显存默认使用可查询空闲量的 60%；无法查询时不超过总量的 25% 和 256 MiB，共享内存再受主机预算限制。
- 显示 CPU 利用率、系统报告频率、GPU 利用率与温度，以及内存使用率、可读的 GPU 频率和功耗。系统报告频率可能为标称值，不作为有效频率或降频依据。
- 运行记录自动保存在 `~/.burnscope/history.sqlite3`；也可通过 `BURNSCOPE_DATA_DIR` 指定位置。上次中断的记录保留，并标为中断。

## 平台范围与取舍

GPU 压力依赖 OpenCL；GPU 监测通过可选 NVML 并按 PCI / UUID 关联。目前可读取受支持的 NVIDIA 指标。AMD、Intel 的 GPU 可以在提供 OpenCL 时测试，但通用接口通常不能提供它们的温度、功耗和利用率；macOS 的 GPU / NVML 可用性同样取决于驱动。

计算错误、监控失联、压力进程异常会停止测试；正常关闭或中断时清理压力进程。父进程意外退出时，子进程通过心跳自行结束。

有 GPU 温度时，连续两次达到 85℃（或设备临界温度减 5℃，取较低值）停止；读数丢失 5 秒停止。GPU 无温度监测时测试自动限制为最多 60 秒。GPU 内核采用短批次并自适应调整，不修改系统超时设置。内存和显存只校验成功分配的区域。

Python 多进程可以占满可用 CPU，但高热强度与专用 AVX 烤机程序不同；系统调度、后台负载、配额和驱动会影响实际利用率，不承诺所有仪表一直显示 100%。程序不改变电压、风扇、功耗限制或超频配置。
